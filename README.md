# 云对象存储可视化管理工具

## 项目简介
本项目是一款基于 `Qt` 构建的云对象存储可视化管理工具，支持存储桶管理、对象管理、文件上传下载等功能。通过 HTTP/HTTPS 协议访问分布式存储服务，提供直观的界面化管理，帮助用户方便地管理云存储资源。

## 功能特点
- **存储桶管理**：创建、查看、删除云存储中的存储桶。
- **对象管理**：获取对象列表、查看对象详情、删除对象。
- **文件上传和下载**：通过 HTTP/HTTPS 协议上传或下载文件。
- **用户管理**：基于 MySQL 实现用户信息的增删改查。
- **界面优化**：使用 `Qt` 提供用户友好的界面设计，支持水平、垂直、网格布局，提升操作体验。

## 技术栈
- **C++/Qt**：构建用户界面，设计交互功能。
- **QNetworkAccessManager**：实现 HTTP/HTTPS 网络请求，处理云存储通信。
- **MySQL**：用于用户信息的存储与管理。
- **QTest**：进行单元测试，确保代码稳定性和可靠性。

### 环境要求
- **操作系统**：Windows/Linux/MacOS
- **开发工具**：Qt 5.x 或更高版本
- **数据库**：MySQL 5.x 或更高版本
